    Importar/Exportar Questões

    Gerencie suas questões importando de um arquivo JSON ou exportando para JSON/CSV.

    Exportar Questões
    Importar Questões

    Selecione um arquivo JSON contendo as questões. Os IDs serão tratados como numéricos. Se um ID importado já existir, a questão será atualizada (se "Adicionar e Atualizar" estiver marcado), caso contrário, um novo ID sequencial será gerado para novas questões.

    Se desmarcado, todas as questões atuais serão substituídas pelas do arquivo (IDs serão re-numerados sequencialmente).

    Exemplo de formato JSON para importação (um array de objetos):

    [
  {
    "id": 1, 
    "text": "Qual a capital da França?",
    "options": ["Berlim", "Madri", "Paris", "Lisboa"],
    "correct": 2,
    "isDisabled": false,
    "difficulty": "facil" 
  },
  { 
    "text": "Quanto é 2+2?",
    "options": ["3", "4", "5"],
    "correct": 1
  }
]

    Configurações Gerais do Quiz

    Dinâmica e Apresentação do Quiz

    Defina as regras de pontuação, tempo, dificuldade e como o quiz se apresenta.

    O quiz selecionará aleatoriamente esta quantidade de perguntas do banco total. Mínimo 1.

    Tempo limite para responder cada pergunta. Mínimo 5s, Máximo 120s.

    A soma deve ser 100%. O sistema tentará atender a esses percentuais com base nas questões disponíveis.

    A soma dos percentuais deve ser 100%.

    Mostrar a alternativa correta após o erro.

    Ex: 10, 20, etc.

    Interface e Experiência do Usuário

    Configure o modo de descanso, alertas visuais e o teclado virtual.

    Tempo de inatividade (15-600s) antes do quiz entrar em modo de descanso.

    Quantos segundos antes do modo descanso o aviso de esmaecimento deve iniciar (3-30s). Deve ser menor que o tempo total para descanso.

    Habilitar Borda Pulsante de Alerta de Tempo

    Se habilitado, uma borda pulsante aparecerá na tela quando o tempo da pergunta estiver acabando.

    Habilitar Flash de Alerta de Tempo

    Se habilitado, um flash sutil aparecerá na tela quando o tempo da pergunta estiver crítico.

    Define a altura do teclado em relação à altura da tela (20vh a 60vh). Padrão: 30vh.

    Habilitar Teclado Virtual

    Se desmarcado, o teclado virtual não será exibido na tela inicial do quiz.

    Gerenciamento de Participantes

    Gerencie as regras para quem pode jogar e quando, e limpe listas de bloqueio.

    Impedir que quem já ganhou um brinde jogue novamente para ganhar.

    Defina por quantos minutos um participante que desistir do quiz ficará impedido de jogar novamente. (0 para desabilitar)
