# Entrega Configurável de Brindes e Resolução de Conflitos Offline

Cada Evento poderá configurar se a entrega de Brinde é imediata (marcada automaticamente como `Entregue` ao atingir a pontuação mínima, para filas rápidas) ou mediante confirmação manual da equipe (`Aguardando Retirada` -> `Entregue`), além de controle opcional de estoque. Caso dois Totens offline premiem o mesmo telefone antes de sincronizar, ambas as Partidas serão preservadas no histórico, consolidando um único Brinde válido para o telefone no Evento e gerando alerta de duplicidade offline no painel.
